
# [PixelPals/Lobby-Game]

> ⚠️ **Status: Archived / Unmaintained**  
> This is a legacy PHP project made for <a href="https://github.com/pmmp/PocketMine-MP">PMMP 3.0.0</a> (MCPE 0.15.10) and preserved for historical purposes only. It is no longer actively developed, updated, or monitored for security vulnerabilities.

</br>

<h2 align="center"><span>About</span></h2>
<p>This is a very basic and fun lobby game, players can click on the signs to get one time gifts (in between 70 to 170 coins as defualt)</p>

</br>

<h2 align="center"><span>Setup</span></h2>

```
coin-add
```

> Writing this on a sign will trigger the plugin, __new.event__ permission is required


</br>

<h2 align="center"><span>Permissions</span></h2>


- **`new.event`**
  - Admin permission

</br>

<h2 align="center"><span>Dependencies</span></h2>

- __PixelPals-Economy-Manager__

</br>

<h2 align="center"><span>File activity</span></h2>

When enabled, the plugin will create:
<br>
- A JSON file at __~/Pixel_Games/marks.game__
- A JSON file at __~/Pixel_Games/claimed.ppl__


</br>

<h2 align="center"><span>Affected events</span></h2>

- BlockBreakEvent
- PlayerInteractEvent
- SignChangeEvent
